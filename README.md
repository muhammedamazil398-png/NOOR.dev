# Noor.dev

Noor is an Islamic digital ecosystem built with React, Vite, Tailwind CSS, and Zustand.

## What it includes

- Quran reading with offline surah download support
- Reciter audio playback
- Hadith browsing in Arabic and English
- Salah guidance, Dhikr, and Islamic learning tools
- Language and accessibility settings
- Easy Read feature to scale the entire app for better readability
- PWA-ready experience with offline home screen support

## Accessibility

Use the `Settings` page after login to change the app scale. The `Easy Read` controls adjust the overall font size, button size, text, cards, and UI layout for better readability.

## Icon

The app icon is designed as an Islamic-themed brand mark for a more appropriate appearance on devices and PWA installations.
